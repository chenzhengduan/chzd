# 线索进入与客户分级

## 本节目标

客户从短视频、社媒、平台询盘、展会、转介绍或线下拜访进入后，先判断需求是否真实、信息是否足够、是否值得立即投入资源。

## 先记录来源，不急着报价

| 必填信息 | 为什么要记 |
| --- | --- |
| 线索来源 | 判断哪个渠道带来的是有效商机，而不只是浏览量 |
| 联系人、公司与角色 | 区分决策人、使用人、中间商和信息收集者 |
| 产品、用途与目标市场 | 决定材质、工艺、质量和合规问题 |
| 预计数量与时间 | 判断打样、产线、供应商和交期是否匹配 |
| 当前阶段 | 初步了解、选型、打样、比价、合同还是复购 |
| 下一步动作与日期 | 防止聊天结束后无人继续推进 |

## 四级线索

| 等级 | 典型状态 | 下一步 |
| --- | --- | --- |
| A：重点商机 | 对象、数量、时间和决策链基本明确 | 当天确认需求会议、样品或正式报价安排 |
| B：有效需求 | 产品和应用明确，但部分条件缺失 | 用需求卡补齐信息，约定下一次回复时间 |
| C：长期培育 | 有方向，没有近期项目或决策时间 | 提供相关案例，进入定期触达，不反复催单 |
| D：暂不匹配 | 需求超出能力、预算或信息长期不完整 | 说明边界，保存原因，必要时转介合适资源 |

!!! warning "不要用国别代替客户判断"
    拜访访谈中出现的地区评价属于受访者个人经历，不能替代对具体客户主体、付款能力、合同条件和订单历史的核验。客户分级看证据，不看标签。

## 第一次沟通的结束标准

- 已知道客户在买什么、为什么买；
- 已知道还缺哪些决定报价的信息；
- 已明确双方下一步由谁、在什么时间完成；
- 暂时无法推进时，也记录停止原因，而不是无限追问。
