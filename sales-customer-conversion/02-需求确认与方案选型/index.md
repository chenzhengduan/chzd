# 需求确认与方案选型

## 本节目标

把“这个多少钱”“能不能做”转成技术、采购和生产都能理解的需求，避免销售先承诺、交付再补条件。

## 通用需求卡

```text
客户/项目：
产品用途：
目标用户与使用场景：
目标市场：
规格、容量与结构：
材料与配套件：
颜色与表面工艺：
预计数量与后续放量：
样品、量产与交付时间：
包装、运输和标签要求：
检验项目、抽样方式与验收标准：
认证、文件与知识产权要求：
预算或目标价格：
尚未确认的问题：
```

## 方案确认顺序

1. **先确认用途**：产品装什么、怎样使用、运输和存放环境是什么。
2. **再确认结构**：主体、泵头、盖、内塞和其他配套由谁提供。
3. **然后确认外观**：颜色、印刷、喷涂、磨砂、光泽和触感要求。
4. **补齐商业条件**：数量、样品、交期、目标市场和预算。
5. **最后确认验收**：用什么样品、记录、测试和判定方法验收。

## 销售承诺前的内部核验

| 要核验的能力 | 需要谁确认 |
| --- | --- |
| 材料、结构与配方/用途适配 | 技术、质量或供应商 |
| 模具、夹具和设备是否匹配 | 工程、生产或外协厂 |
| 稳定产能、换线与交期 | 生产计划与供应链 |
| 包装、防刮和运输方式 | 质量、仓储与物流 |
| 检验方法和不良责任 | 质量、业务与合同负责人 |

!!! tip "不知道并不可怕"
    可以明确告诉客户“这个条件需要技术确认后回复”。未经核验的即时承诺，通常比晚一点给出准确答案更昂贵。
