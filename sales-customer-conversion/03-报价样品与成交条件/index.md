# 报价、样品与成交条件

## 本节目标

让报价不只剩一个单价，而是能够说明对应的产品、数量、工艺、质量、交付和责任边界。

## 一份可执行报价至少包含

| 项目 | 应写清什么 |
| --- | --- |
| 产品版本 | 图纸、样品、材料、结构、颜色和工艺版本 |
| 数量阶梯 | 每个数量区间对应的单价和最小起订条件 |
| 一次性费用 | 打样、模具、版费、夹具、设计或测试费用 |
| 配套范围 | 主体、泵头、盖、包装、标签分别由谁供应 |
| 质量口径 | 检验项目、判定依据、样品和允许边界 |
| 付款条件 | 预付款、尾款、账期、币种和收款节点 |
| 交付条件 | 交期起算点、包装、运输、贸易或交货条件 |
| 报价有效期 | 原材料、汇率或方案变化后怎样重新确认 |

## 定制项目特别注意

- 先区分通用件、现有模具和客户专属开发；
- 说明模具、图纸、Logo 和专属结构的所有权及使用范围；
- 无法转售的颜色、结构或专属库存，要在生产前约定付款和取消责任；
- 开模费、样品费是否可在量产后抵扣，必须写进报价或合同；
- 任何现场口头报价都需要回到规格、数量和日期后重新确认。

!!! warning "访谈中的数字不是报价表"
    2026-07-12 的两次拜访包含开模、加工、设备、展会和团队成本等口述数字。这些数字缺少完整规格、合同和会计口径，只能作为下一次询价时的提问线索，不能直接用于对外报价或行业基准。
