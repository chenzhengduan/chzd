# 订单跟进与交付协同

## 本节目标

订单成交后，把瓶胚、成型、印刷、喷涂、配套、质检和装箱等多个环节，变成有负责人、有时间、有状态的交付流程。

## 订单节点表

| 节点 | 必须记录 |
| --- | --- |
| 订单交接 | 最终版本、数量、价格、付款、交期和特殊要求 |
| 物料与模具 | 到位时间、归属、状态和异常负责人 |
| 首件/样品确认 | 谁确认、确认什么、确认结果和版本 |
| 各工序生产 | 计划、实际完成、在制数量和待解决问题 |
| 检验与包装 | 检验口径、结果、包装方式和放行人 |
| 出货与签收 | 箱单、批次、运输、签收和尾款状态 |

## “盘单”转成可执行动作

现场受访者反复提醒：多环节订单如果无人主动跟进，可能长期停在某个加工点。这里不把“勤催”当方法，而是落实为：

1. 每个环节只有一个明确主责人；
2. 每个节点有计划完成日和实际状态；
3. 上一环节完成后，下一环节必须确认接收；
4. 延误、数量差异和质量异常进入问题清单；
5. 任何口头变更都回写到订单版本并通知相关方。

!!! danger "责任不能等出问题后再猜"
    当瓶体和泵头来自不同供应方，或生产经过多家外协厂时，要在成交前明确匹配测试、漏液、不良、返工、补货和运输成本分别由谁承担。
