# 售后、复购与客户资产

## 本节目标

售后不是只处理赔偿。每次异常和复购都应补全客户、产品、供应商和成本信息，让下一张订单更容易判断。

## 客诉处理顺序

1. 保存批次、数量、图片、视频、样品和客户原始描述；
2. 区分外观、尺寸、功能、配套、包装、运输或使用问题；
3. 对照合同、确认样和检验记录，不凭聊天印象判责；
4. 先约定临时止损方案，再确定返工、补货、折让或赔付；
5. 记录直接损失、运费、挑选、返工、沟通和客户流失风险；
6. 把原因和预防动作写回下一次报价、样品或检验要求。

## 复购前重新确认

- 上次产品版本是否继续使用；
- 数量、颜色、工艺、包装和交期是否变化；
- 上次异常是否已经关闭；
- 原材料、汇率、运输或供应商条件是否变化；
- 是否出现新的市场、法规或客户验收要求。

## 客户资产卡

```text
可否请求案例授权或转介绍：
```

!!! note "转介绍来自可复述的交付结果"
    现场访谈认为客户转介绍相对可靠。项目中把它作为受访者经验保留；真正复盘时，仍应记录每条转介绍的数量、质量、成交和复购，而不是只凭印象判断渠道好坏。
