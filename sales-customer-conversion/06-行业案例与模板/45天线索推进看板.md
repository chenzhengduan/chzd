# 当天响应到 45 天线索推进看板

> 这套看板用于把短视频、评论、私信、展会和转介绍带来的线索推进到明确下一步。它不承诺 45 天成交；它保证团队能看见客户卡在哪里、下一步由谁完成。

<div class="growth-banner">
  <strong>结果口径</strong>
  <span>当天完成线索归档与首次回应；15 天内争取形成有效需求、样品、报价或会议中的一种进展；30～45 天形成可诊断的销售漏斗。</span>
</div>

## 当天：10 分钟建立线索卡

先回复，再把以下信息写进同一张卡。信息不全可以留空，但必须写下一步。

```text
线索编号：
进入时间 / 渠道 / 内容编号：
客户 / 公司 / 国家地区：
产品与使用场景：
规格 / 材料 / 工艺：
预计数量 / 目标时间：
现有样品、图纸或参考图：
需要我们解决的问题：
当前阶段：待判断 / 需求确认 / 样品 / 报价 / 决策 / 暂缓
下一动作 / 负责人 / 截止时间：
```

### 第一次回复模板

> 收到。为了判断现有规格能否直接匹配，麻烦先给我产品用途、容量/尺寸、预计数量和目标交期；有参考图或现有样品也可以一起发。资料齐后，我们会先确认可行方案和需要打样的部分，再给有效报价。

不要一上来发送整本目录，也不要在数量、工艺和交期未知时给一个看似准确的裸价。

## 1～15 天：锁定一个可验证进展

每条线索至少走向一个分支：

| 分支 | 进入条件 | 15 天内的有效证据 | 下一步 |
| --- | --- | --- | --- |
| 需求确认 | 客户有真实场景，但资料不完整 | 用途、规格、数量、工艺、交期至少明确四项 | 方案或补资料清单 |
| 样品 | 外观、适配或性能需要实物验证 | 样品版本、费用、寄送信息、确认项目和反馈日期 | 样品确认或改版 |
| 报价 | 关键条件已明确 | 带版本号、数量阶梯、税运口径、有效期和责任边界的报价 | 客户确认差异与决策人 |
| 会议 | 多角色、多工艺或风险较高 | 会议时间、参会人、议题和会后动作 | 样品、报价或技术确认 |
| 培育 | 暂无采购时间或需求不匹配 | 暂缓原因、重新联系时间和可提供的有用资料 | 到期再联系 |

“发过消息”“客户看过”“报过价格”不算进展；能留下版本、时间、负责人或客户确认才算。

## 有效样品确认单

```text
样品编号 / 版本：
客户用途：
确认项目：外观 / 尺寸 / 适配 / 密封 / 颜色 / 手感 / 其他
不包含的测试：
样品数量与费用：
寄送方式与地址确认：
客户反馈截止日：
通过标准：
未通过后的处理方式：
```

## 有效报价最低字段

- 产品名称、规格、材料和工艺版本；
- 数量阶梯、单价、币种、税费与运费口径；
- 模具、夹具、打样及定制色等一次性费用；
- 付款条件、生产周期、报价有效期；
- 包装、验收、损耗和异常责任边界；
- 客户还需要确认的事项。

### 报价后跟进模板

> 上次报价中，影响方案的主要变量是 `__`。你们现在更需要确认价格、样品效果、交期，还是内部决策资料？我可以按优先项补一版，避免重复发送无关信息。

客户没有回复时，不要连续发送“在吗”。带着新信息联系：相似问题的选择清单、样品结果、交期变化或一个需要客户确认的具体问题。

## 16～30 天：用阶段出口管理商机

| 阶段 | 进入证据 | 离开该阶段必须具备 |
| --- | --- | --- |
| 待判断 | 有联系方式或互动 | 明确是否存在真实业务场景 |
| 需求确认 | 客户愿意补资料 | 关键需求与缺口清单 |
| 方案/样品 | 已确定验证路径 | 客户对版本或结果的反馈 |
| 报价 | 报价条件完整 | 客户异议、决策链与下一日期 |
| 决策 | 方案和商务条件可比较 | 下单、暂缓或失败原因 |
| 交付/复购 | 订单成立 | 节点、异常、验收和复购机会 |

每张卡必须有“下一动作、负责人、截止时间”。没有下一动作的卡，不是商机，只是通讯录。

## 31～45 天：看板与指标

建议每周固定一次 30 分钟盘单：先处理逾期动作，再看阶段分布，最后把高频客户问题返给内容团队。

| 指标 | 计算口径 | 用来判断什么 |
| --- | --- | --- |
| 当天归档率 | 当天建卡线索 ÷ 当天新线索 | 是否漏接 |
| 下一步锁定率 | 有负责人和日期的线索 ÷ 已归档线索 | 是否只聊不推进 |
| 15 天进展率 | 15 天前进入且已产生需求/样品/报价/会议证据的线索 ÷ 同批成熟线索 | 内容与销售承接是否有效 |
| 无下一动作占比 | 无负责人或日期的进行中线索 ÷ 进行中线索 | 看板是否失真 |
| 合格线索率 | 符合目标客户定义的线索 ÷ 新线索 | 内容是否吸引对的人 |
| 制作投入 | 每个选题的拍摄、剪辑和发布工时 | 获客是否可持续 |

“15 天进展率”只比较已经观察满 15 天的同批线索，避免拿昨天的新询盘当失败。

## 内容与销售怎么互相喂数据

```text
视频/帖子编号 → 评论或私信 → 线索编号 → 当前阶段 → 结果 → 新选题
```

- 销售每周提交 3 个反复出现的客户问题；
- 内容团队把问题拍成“一个问题＋一个证据＋一个边界＋一个下一步”；
- 发布时保留内容编号，进入私信后写入线索卡；
- 45 天后既看播放和互动，也看合格线索、样品、有效报价和会议。

## 使用边界

这是一套制造业 B2B 操作模板，不是行业统一成交周期。大额、定制、跨境、认证或多角色采购通常更长；30～45 天的目标是获得真实信号并形成可诊断流程，而不是人为催促客户下单。
