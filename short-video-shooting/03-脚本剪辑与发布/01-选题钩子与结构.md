# 选题、钩子与结构

## 本节目标

把“今天拍一下工厂”改写成一个有受众、有问题、有证据的具体选题。

## 先写四个字段

| 字段 | 问题 | 示例 |
| --- | --- | --- |
| 受众 | 谁需要知道？ | 正在找精华瓶供应商的品牌方 |
| 问题 | 他正在判断什么？ | 为什么外形相同报价不同？ |
| 证据 | 什么画面能证明？ | 克重、壁厚、泵头测试、喷涂细节 |
| 行动 | 看完做什么？ | 留言用途/容量，索取选型表 |

如果“证据”一栏只能写口播形容词，这个选题还不够可拍。

## 四类通用钩子

1. **结果先给**：先展示最整齐、最意外或最明确的结果。
2. **问题直击**：直接说目标受众正在遇到的具体问题。
3. **过程奇观**：第一帧就是吹瓶、脱模、喷涂或高速排列。
4. **反常识判断**：指出一个常见误区，并马上给可验证画面。

示例：

- “同样是 30ml 精华瓶，价格为什么能差三倍？”
- “别先看瓶身，采购泵瓶先检查这个位置。”
- “这颗瓶胚，几秒后会变成完整瓶子。”
- “不是越厚的瓶子，质量就一定越好。”

不要先说“大家好，今天带大家参观我们工厂”，也不要用 Logo 片头消耗第一屏。

## 15–30 秒的证据型结构

```text
0–3 秒：问题/结果/奇观，只负责让目标观众停下
3–8 秒：交代对象和判断标准
8–20 秒：2–3 组过程或检测证据
20–26 秒：给出结论、适用边界或选择建议
26–30 秒：自然行动提示或下一集问题
```

第一条先只回答一个问题。不要把公司历史、全部工艺、十个卖点和联系方式塞进同一条。

## 钩子测试练习

为同一个主体写三个开头：

- A：采购问题；
- B：视觉奇观；
- C：反常识结论。

三个版本共用后续主体，只替换前 2–3 秒。发布后不要只比播放量，还要比较目标客户的有效评论、主页访问和询盘。

## 验收标准

- [ ] 钩子能在静音第一帧建立“与我相关”或“我没见过”；
- [ ] 全片只回答一个主要问题；
- [ ] 至少有两个可见证据支撑结论；
- [ ] 结论包含适用条件，不做无法验证的绝对化承诺；
- [ ] CTA 与目标一致，不是机械地要求点赞关注。
