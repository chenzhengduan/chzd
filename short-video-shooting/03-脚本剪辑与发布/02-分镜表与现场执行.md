# 分镜表与现场执行

## 本节目标

把抽象脚本变成现场能逐项拍完、拍完能核对的镜头清单。

## 分镜表的七个字段

| 字段 | 写什么 |
| --- | --- |
| 编号 | 镜头顺序与备用版本 |
| 功能 | 钩子、交代、证据、转折、结论、行动 |
| 画面 | 主体执行的可见动作 |
| 景别/机位 | 全景、中景、特写；平视、俯拍、仰拍 |
| 台词/字幕 | 只写结论或必要信息，不重复描述画面 |
| 声音 | 人声、环境声、具体动作声、音乐 |
| 验收 | 对焦点、动作完成、标签可读、无敏感信息等 |

## 一镜只承担一个功能

例如“展示车间规模、解释材料、突出老板专业、顺便让客户咨询”无法在一个镜头内完成。应该拆为：

1. 对称全景：只交代生产线规模；
2. 操作中景：只展示人员和设备配合；
3. 材料特写：只证明材料/结构；
4. 人物中近景：只给出专业判断；
5. 成品镜头：只承接咨询行动。

## 现场执行顺序

不要完全按成片顺序拍。更高效的顺序是：

1. 按场地拍完所有全景；
2. 按工序拍完所有中景；
3. 在不影响生产的位置集中拍特写和动作声；
4. 最后录口播、补拍转场和干净成品；
5. 每换一个场地，当场回看关键镜头后再离开。

## 每镜三次法

- 第一次：确认构图、曝光和对焦；
- 第二次：追求完整、稳定的标准动作；
- 第三次：拍不同速度、角度或更近景作为备选。

不要用“后期能救”替代现场检查。严重失焦、过曝和爆音通常无法可靠修复。

## 验收标准

- [ ] 每镜都有唯一功能和具体动作；
- [ ] 钩子、核心证据和结论至少各有一个备选；
- [ ] 关键动作从开始前录到结束后；
- [ ] 离开场地前已回看对焦、曝光、声音和敏感信息；
- [ ] 分镜表能让另一位拍摄者照表完成，而不依赖口头解释。
