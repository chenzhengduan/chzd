# 剪辑、字幕与声音

## 本节目标

把素材剪成信息清楚、节奏自然、关闭声音也能理解的短视频。

## 第一遍：只做信息剪辑

1. 按“钩子 → 对象 → 证据 → 结论 → 行动”排列镜头。
2. 删除失焦、重复、动作不完整和不能提供新信息的镜头。
3. 操作镜头保留完整动作，钩子和结果镜头可以更短。
4. 先使用硬切；只有时间、地点或状态变化需要强调时才加转场。
5. 通看一遍：删掉某镜如果仍能理解，就删掉。

## 第二遍：处理节奏

- 钩子/结果镜：通常 0.5–1.5 秒；
- 普通叙事镜：通常 2–4 秒；
- 操作/检测镜：通常 3–5 秒，让观众看完动作和读完数字；
- 重要信息前可以短暂停顿，连续快切只用于明确的节奏爬升；
- 不要为了“快”剪掉证据，不要为了“高级”保留无信息空镜。

这些是起步范围，不是算法定律。最终以“看清、听懂、不拖沓”为准。

## 字幕原则

- 一屏只表达一个意思，优先短句；
- 关键数字、材料名、工艺名可以突出，但不要全屏同时跳动；
- 字幕避开顶部标题区、底部说明区和右侧交互按钮；
- 字幕说判断，画面给证据，避免逐字描述正在发生的动作；
- 涉及产品颜色、尺寸和检测结果时，保持术语准确。

## 声音处理顺序

1. 先保证口播/采访清楚；
2. 再保留关键真实动作声；
3. 补充必要环境声，避免镜头切换后空间完全“死掉”；
4. 最后才加音乐，并把音乐压到不遮挡信息的位置；
5. 在关键动作处让声音与画面同帧发生。

机器声、按压声、合模声可以成为内容证据。不要用夸张音效伪装不存在的脆度、密封、力度或速度。

## 导出前检查

- [ ] 9:16，至少 1080 × 1920；
- [ ] 无黑边、无剪辑软件水印、无未授权素材；
- [ ] 字幕没有被平台界面遮挡；
- [ ] 手机扬声器和耳机都能听清；
- [ ] 成片没有订单号、客户 Logo、内部参数或员工未授权正脸；
- [ ] 数据、测试次数和材料描述与真实记录一致。
