# 发布测试与复盘

## 本节目标

用“小范围、单变量”的方式改进内容，而不是每条都换题材、换风格后凭感觉判断。

## 发布前先写假设

示例：

> 采购用户更关心“怎么判断泵头质量”，所以检测特写开头会比车间全景带来更多有效停留和咨询。

一条假设只改变一个主要变量：开头、时长、字幕方式、口播人设或结尾行动，避免同时全部改变。

## 三层指标

| 层级 | 看什么 | 说明什么 |
| --- | --- | --- |
| 注意力 | 前段留存、平均观看、完播/有效观看 | 开头与节奏是否让人继续看 |
| 价值 | 收藏、分享、专业问题、重复观看 | 内容是否有用或值得传播 |
| 业务 | 主页访问、私信、表单、样品/报价询问 | 是否吸引了目标客户 |

平台对“播放”的定义可能调整，不同平台也不能直接横比。优先观察同一账号、同一时期、相似题材之间的趋势。

## 一条视频的复盘卡

```text
视频编号/链接：
目标受众：
核心问题：
测试变量：
表现最好的 3 秒：
明显流失位置：
评论中的真实问题：
产生的有效业务动作：
保留什么：
下一版只改什么：
```

## 三轮迭代法

1. **第一轮测开头**：主体内容不变，测试问题型、奇观型、结果型开头。
2. **第二轮测证据**：保留胜出开头，比较过程、对比或检测证据。
3. **第三轮测行动**：比较“留言问题”“索取选型表”“查看下一集”等不同收口。

有效钩子可以复用，但必须匹配新内容；不要为了数据制造虚假冲突、伪造检测或诱导无关评论。

## 验收标准

- [ ] 发布前记录了目标和单一测试变量；
- [ ] 复盘同时看内容指标和业务指标；
- [ ] 能指出具体流失镜头，而不是笼统说“流量不好”；
- [ ] 下一版只改一个主要因素；
- [ ] 把高表现镜头、声音和文案沉淀进素材库。
