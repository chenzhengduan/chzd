# 瓶胚与吹瓶过程

## 本节目标

把“瓶胚经过设备成为瓶子”的过程拍得既有视觉吸引力，又能让观众理解关键工序。

## 必拍镜头

| 工序 | 全景/中景 | 特写证据 |
| --- | --- | --- |
| 瓶胚准备 | 容器、上料路径 | 瓶胚外形、口部、颜色 |
| 加热/输送 | 设备运行和移动方向 | 允许拍摄的加热/传送细节 |
| 入模与成型 | 设备局部和安全距离 | 合模、成型瞬间或可见状态变化 |
| 脱模/取件 | 机械手或成品输出 | 瓶身刚成型的状态 |
| 冷却/输送 | 成品进入下一环节 | 瓶口、瓶底和壁面 |
| 检查 | 人员/设备执行检查 | 缺陷示例或检测读数（经授权） |

## 20 秒过程脚本

```text
0–2 秒：瓶胚与成品同屏
字幕：它不是缩小版瓶子，而是成型前的瓶胚。

2–5 秒：瓶胚上料和输送
5–9 秒：成型关键动作 + 真实机械声
9–13 秒：成品连续输出
13–17 秒：瓶口、瓶底、壁面检查
17–20 秒：瓶胚 → 成品并排
结论：稳定不只看“吹出来”，还要看每一只是否一致。
```

## 拍摄技巧

- 第一镜用瓶胚和成品建立比例反差；
- 高速动作固定机位拍，计划慢放时使用 60fps；
- 机器内部只拍获准区域，不能拆防护或越线取景；
- 单独收录一遍合模、取件、落瓶或输送声；
- 用手持样品特写连接不同设备段落，帮助观众理解流程；
- 时间压缩、慢动作或流程演示需要如实说明。

## 可讲的专业点

- 不同瓶胚外观与最终瓶型之间的关系；
- 为什么瓶口通常先已成型、瓶身在后续变化；
- 壁厚、瓶底、外观一致性为何需要检查；
- 换模、换料、首件确认分别解决什么问题。

只讲现场可以核验、企业允许公开的内容。不要用一条产线或一个样品代表所有材料和工艺。

## 验收标准

- [ ] 普通观众能复述瓶胚到瓶子的基本顺序；
- [ ] 至少有一个状态变化镜头和一个检查镜头；
- [ ] 快速动作清楚，无明显频闪；
- [ ] 没有把演示镜头伪装成连续真实工序；
- [ ] 机位、人员和设备操作符合现场安全要求。
