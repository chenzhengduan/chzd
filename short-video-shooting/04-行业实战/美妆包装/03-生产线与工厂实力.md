# 生产线与工厂实力

## 本节目标

用空间、流程、人物和细节证明工厂能力，而不是只拍一段“机器很快”的素材。

## 工厂实力的四层证据

| 层级 | 画面 | 回答的问题 |
| --- | --- | --- |
| 空间 | 车间、产线、仓库全景 | 有没有对应设备和生产空间？ |
| 流程 | 上料、成型、转运、检查、装箱 | 工序是否完整、衔接是否清楚？ |
| 人物 | 调机、首件确认、巡检、记录 | 谁在控制稳定性？ |
| 结果 | 成品、检测记录、批次状态 | 最终如何证明一致和可交付？ |

规模镜头提供注意力，人物和记录镜头提供信任。只拍无人机器，采购方很难判断过程是否受控。

## 一条产线的拍摄顺序

1. 在获准位置拍对称/纵深全景，交代空间。
2. 固定中景拍原料或部件进入流程。
3. 按物料移动方向依次拍 3–5 个关键工序。
4. 拍操作员确认、调整或记录的动作。
5. 拍成品连续输出和整齐排列。
6. 拍抽检、标识或装箱，完成闭环。

## 30 秒脚本示例

```text
0–3 秒：成品高速输出特写
“一天出多少不是最重要，重要的是每一只都一致。”

3–7 秒：产线纵深全景
7–15 秒：上料 → 成型 → 输送，按方向连续切换
15–21 秒：操作员首件/巡检/记录
21–26 秒：抽检与成品排列
26–30 秒：结论 + 下一集问题
“下一条看这批瓶子为什么在这里被拦下。”
```

## 产能数字怎么表达

- 只有在统计口径明确时才说日产/班产/节拍；
- 说明这是单机、单线、某瓶型还是整个工厂；
- 区分理论速度与稳定生产状态；
- 不用短时间高速镜头推导全天产量；
- 涉及客户和商业机密时使用获准的区间或不公开。

## 验收标准

- [ ] 至少包含空间、流程、人物和结果四层证据；
- [ ] 物料运动方向在剪辑中基本一致；
- [ ] 生产线画面没有客户敏感信息；
- [ ] 产能和效率数字有明确口径；
- [ ] 没有为了镜头要求员工改变安全操作。
