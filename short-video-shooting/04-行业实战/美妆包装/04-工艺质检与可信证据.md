# 工艺、质检与可信证据

## 本节目标

把“工艺精、质量好”改成看得见、能理解、可复核的内容。

## 工艺视频：一定拍前后与过程

喷涂、丝印、烫金、电镀等内容至少包含：

1. 工艺前的基材状态；
2. 获准拍摄的工艺动作/设备局部；
3. 工艺后的完整效果；
4. 角度变化下的细节；
5. 对应的检查或不良示例。

同屏对比必须尽量保持光线、角度、焦段和曝光一致，否则观众看到的差异可能来自拍摄而不是工艺。

## 质检视频：先说问题，再拍方法

| 要判断什么 | 可拍证据 | 不能只拍什么 |
| --- | --- | --- |
| 密封/漏液风险 | 真实样品、步骤、时间、前后状态 | 只把瓶子倒过来一秒 |
| 泵头使用状态 | 连续按压、出液/回弹、记录方式 | 只按一次并说“很顺” |
| 表面附着 | 获准的测试方法、前后细节 | 随意用指甲刮 |
| 尺寸/配合 | 量具、测量位置、读数或判定 | 量具一闪而过 |
| 跌落/运输风险 | 条件、次数、高度/包装状态、结果 | 夸张摔一下就下绝对结论 |
| 外观一致性 | 色卡/标准样/光源下对照 | 滤镜前后对比 |

测试标准、条件和结论以企业真实 SOP、客户要求或适用标准为准。本教程不替代质量规范。

## 15 秒质检脚本

```text
0–2 秒：不良与合格样品同屏
“这两只看起来一样，为什么一只不能出货？”

2–5 秒：指出一个具体检查位置
5–10 秒：完整拍一次检查动作和读数/结果
10–13 秒：合格与不合格细节对比
13–15 秒：结论和适用边界
“外观只是第一关，最终按这批产品的检验要求判定。”
```

## 主动暴露边界更可信

可以公开说明：

- 某种工艺成本更高、周期更长；
- 小批量不适合某条自动化产线；
- 某材质不适合特定配方或使用环境；
- 样品效果与量产之间需要首件和批次控制；
- 视觉演示不能替代正式测试报告。

## 验收标准

- [ ] 观众能说出测试对象、方法和判断结果；
- [ ] 工艺前后对比条件一致；
- [ ] 数字和结论有真实记录可追溯；
- [ ] 不用虚假音效、滤镜或剪辑伪造性能；
- [ ] 明确说明适用条件和不能证明的部分。
