# 拍摄清单与分镜模板

## 拍摄前检查

### 内容

- [ ] 目标受众明确；
- [ ] 一条视频只回答一个主要问题；
- [ ] 至少准备两个可见证据；
- [ ] 钩子、结论与行动一致；
- [ ] 所有数字、材料和工艺结论可核验。

### 现场

- [ ] 镜头、样品、背景清洁；
- [ ] 电量、存储、勿扰模式正常；
- [ ] 曝光、对焦、白平衡和帧率已测试；
- [ ] 灯光无明显频闪，声音不过载；
- [ ] 已确认人员、客户产品和现场信息授权；
- [ ] 机位不影响人员、通道、设备和安全设施。

## 单镜自检

1. 这镜只承担钩子、交代、证据、结论或行动中的哪一个？
2. 观众应该看哪里，对焦和光线是否支持？
3. 机位为什么要动？没有明确理由就固定。
4. 台词与画面是否互补，而不是重复？
5. 声音是否真实同步，能否帮助证明动作？
6. 删除这镜后如果不影响理解，是否应该删除？
