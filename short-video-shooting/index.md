## 默认技术基线

| 优先级 | 起步做法 | 为什么 |
| --- | --- | --- |
| 画幅 | 竖屏 `9:16`，至少 `1080 × 1920` | 适配当前主流短视频浏览方式 |
| 画面 | 后置主摄、固定机位、锁曝光与对焦 | 先得到稳定、可剪的素材 |
| 声音 | 保留关键真实动作声 | 让工艺和操作更可信 |
| 信息 | 字幕和主体避开界面区域 | 不让关键结论被按钮遮住 |
| 表达 | 一条只讲一个判断问题 | 让观众看完能复述结论 |

!!! note "为什么默认从竖屏开始"
    TikTok 官方创意建议以全屏 9:16、至少 720P 和 UI 安全区为基础；YouTube Shorts 官方教程同样建议手机竖拍，并强调柔和均匀的光线、干净的声音和拍摄前分镜清单。本栏目把这些作为跨平台起点，再针对国内平台发布界面做成片检查。
