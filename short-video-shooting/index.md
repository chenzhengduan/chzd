# 短视频拍摄实操

这是一套从“拿起手机能拍”逐步走到“能为具体行业稳定生产内容”的实操教程。它不要求先买相机，也不把流量口号当作拍摄知识；每一节都通过一个小成片练习，把画面、声音、脚本和业务目标连起来。

## 这套栏目怎么学

```text
第一条能看清的视频
  → 手机设置与现场准备
  → 景别、光线、声音、稳定
  → 钩子、结构、分镜、剪辑
  → 发布测试与数据复盘
  → 行业专用镜头与转化脚本
```

建议按顺序完成。每篇控制一个核心能力，并统一提供：

- **本节目标**：学完能独立完成什么；
- **最低设备**：先用已有设备，不把采购器材当作进步；
- **跟拍步骤**：可以直接照做的小示例；
- **验收标准**：用可观察的结果判断是否完成；
- **常见错误**：说明失败画面为什么失败；
- **进阶改法**：基础动作稳定后再增加难度。

## 学习路线

| 阶段 | 要解决的问题 | 最终作业 |
| --- | --- | --- |
| 入门 | 画面不乱、主体清楚、声音可用 | 7 镜头、15 秒物品视频 |
| 基本功 | 会选景别、机位、光线和运动方式 | 同一物品的完整镜头组 |
| 内容组织 | 会写钩子、结构和可执行分镜 | 一张能在现场逐项勾选的分镜表 |
| 后期发布 | 会剪、会测、会用数据改下一条 | 同素材两个开头版本 |
| 行业实战 | 把行业知识翻译成可见证据 | 一条有明确业务目标的成片 |

## 当前行业子栏目

### 美妆包装、瓶器与生产线

从单只瓶器的材质表现开始，逐步学习瓶胚、吹瓶、丝印/烫金/喷涂、生产线、检测与询盘型视频。这里特别强调三件事：

1. 让透明、反光、磨砂等材质真实可见；
2. 用过程和检测证明专业能力，不用空泛口号；
3. 同时满足普通观众的“看得懂”和采购客户的“判断得了”。

## 默认技术基线

- 竖屏 `9:16`，至少 `1080 × 1920` 输出；
- 主体与关键字幕避开顶部、底部和右侧的平台界面区；
- 第一轮优先使用手机后置主摄、固定机位和自然/常亮光；
- 先保证曝光、对焦和白平衡稳定，再追求运镜和特效；
- 拍摄时每个镜头前后各多留约 1 秒，方便剪辑；
- 所有产能、合格率、测试次数与材料结论必须可核验。

!!! note "为什么默认从竖屏开始"
    TikTok 官方创意建议以全屏 9:16、至少 720P 和 UI 安全区为基础；YouTube Shorts 官方教程同样建议手机竖拍，并强调柔和均匀的光线、干净的声音和拍摄前分镜清单。本栏目把这些作为跨平台起点，再针对国内平台发布界面做成片检查。
