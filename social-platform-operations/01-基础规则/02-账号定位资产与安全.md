# 账号定位、资产与安全

> 用时：约 45 分钟<br>
> 结果：得到一份可以交接、可以找回、可以持续发布的账号底稿

## 一句话定位

用这个句式写，不要先想“我要做一个大号”：

> 给【具体人群】看【具体场景中的问题】，用【内容证据】帮助他们做出【具体判断或行动】。

美妆包装工厂示例：

> 给寻找包装供应商的品牌采购和产品经理，看瓶器、工艺、质检和生产过程，用真实细节帮助他们判断材质、品质、交期与供应能力。

## 三个内容支柱

| 支柱 | 要回答的问题 | 美妆包装示例 |
| --- | --- | --- |
| 看懂产品 | 这是什么，有什么差异 | PET、PP、玻璃、亚克力瓶怎么区分 |
| 看懂过程 | 它怎样被制造和验证 | 瓶胚、吹瓶、喷涂、丝印、密封测试 |
| 看懂选择 | 什么情况适合、有什么代价 | 起订量、模具、交期、报价差异 |

三类内容足够支撑首批 15～30 条。定位不是要求每条一模一样，而是让平台与观众有足够样本判断“为什么要关注你”。这是运营方法，不是官方账号标签规则。

## 账号资产表

建立一个受控表格或密码管理器，至少记录：

- 平台、账号 ID、主页链接和创建日期；
- 注册主体、管理员与实际使用人；
- 绑定邮箱、手机号、恢复方式；
- 双重验证方式与备用恢复码存放位置；
- 企业认证、付款、税务和合同主体；
- 音乐、字体、图片、商标与人物授权文件；
- 账号异常、申诉和平台工单记录。

不要把密码、身份证照片、验证码和恢复码直接写进公开文档或普通聊天群。

## 安全基线

- 每个平台使用不同的长密码；
- 能开双重验证就开启，优先验证器或安全密钥；
- 管理员使用平台提供的角色/团队权限，不共用个人密码；
- 删除离职人员和失效机构的访问权限；
- 登录异常只走官方安全中心，不购买“解封”“强开权限”服务；
- 每月检查绑定方式、活跃会话、第三方应用和付款账号；
- 企业号准备营业执照、商标/授权和法人资料，但仅在官方页面提交。

## 资料页最小集合

| 项目 | 合格标准 |
| --- | --- |
| 头像 | 小尺寸仍能辨认，品牌标识有权使用 |
| 名称 | 可读、可搜索，不仿冒官方或他人 |
| 简介 | 说明为谁解决什么问题，不堆无关关键词 |
| 联系方式 | 只放平台允许的位置和方式 |
| 地区/语言 | 与实际业务和内容语言一致 |
| 商业身份 | 需要时使用企业/专业账号并完成认证 |

## 验收清单

- [ ] 一句话定位能明确说出人群、问题和证据
- [ ] 已定义三个内容支柱
- [ ] 账号恢复方式由企业或本人可控
- [ ] 已开启可用的双重验证
- [ ] 管理权限没有共享密码
- [ ] 品牌、人物、音乐与客户资料有授权路径
- [ ] 账号资料没有违规导流或夸大承诺
