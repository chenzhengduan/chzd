# Facebook：账号门槛与健康启动

> 核验日期：2026-07-13<br>
> 官方依据：Facebook Help Center、Meta Newsroom 与 Monetization Policies

## 门槛快照

| 能力 | 当前公开条件 | 说明 |
| --- | --- | --- |
| 创建个人账号 | 原则上至少 13 岁，部分地区可能不同 | 13～17 岁适用 Teen Account 保护；较低年龄公开发帖/专业模式可能需监护人许可 |
| 主页 Page | 由有权限的真实个人账号创建和管理 | 企业资产应使用角色权限，不共享个人密码 |
| 专业模式 | 可在个人主页开启，不会另建一个 Page | 提供洞察、公开关注和创作者工具；不等于自动变现 |
| Content Monetization | 截至 2026-03 仍为邀请制，可在专业后台提交兴趣 | 官方没有公布面向全部创作者的统一粉丝或观看门槛 |

## 个人专业模式还是 Page

- 个人专家、创始人或内容创作者：可考虑在真实个人主页开启 Professional Mode；
- 品牌、工厂、门店和多人团队：使用 Facebook Page，并通过 Meta 的角色/业务权限管理；
- 不要为企业创建假个人身份，也不要让多人共用一个个人密码。

## 推荐与变现关键点

“允许留在 Facebook”不代表“符合推荐资格”。Meta 明确可能降低以下内容的推荐或变现：

- 购买点赞、协调虚假互动或垃圾账号行为；
- 无关长文案、过量/无关标签；
- 批量重复内容和低价值改编；
- 无实质增值的搬运；
- 夸张健康/金融结论、虚假信息；
- 近期反复违规或持续发布不可推荐内容。

自己拍摄或制作的内容更容易被认定为原创；只加边框、字幕、变速或简单拼接通常不足以把他人内容变成原创。

## 健康启动

1. 建立 Page 或开启 Professional Mode，完善 About、类别和联系信息。
2. 用 Security Checkup、唯一密码和双重验证保护个人及企业资产。
3. 将 Reels、较长解释视频、图片和文字案例组合发布，不只复制其他平台短视频。
4. 在内容中明确工厂、人物、地点和产品归属，避免让用户误认官方或客户身份。
5. 用 Professional Dashboard 查看受众、内容、推荐状态和变现邀请。
6. 任何收益资格只以后台显示和官方邀请为准。

## 不可信的说法

- 新 Page 必须先发若干天文字才能发 Reels；
- 开启专业模式就会自动增加或降低流量；
- 旧版 In-stream Ads/Ads on Reels 门槛仍适用于当前全部 Content Monetization；
- 买少量点赞可以帮助账号获得推荐；
- 同一视频批量发多个主页不会影响原创与垃圾内容判断。
