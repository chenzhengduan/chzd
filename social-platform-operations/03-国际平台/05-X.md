# X：账号门槛与健康启动

> 核验日期：2026-07-13<br>
> 官方依据：X Help、X Rules 与 Creator Monetization Standards

## 门槛快照

| 能力 | 当前公开条件 | 说明 |
| --- | --- | --- |
| 创建和使用账号 | 至少 13 岁 | 已知 13～17 岁账号默认 Protected posts；部分地区可能需监护人同意 |
| 发布帖子/视频 | 普通合规账号可发布 | Protected 状态影响公开发现范围 |
| Creator Revenue Sharing | Premium 系列订阅 + 最近 3 月 500 万自然曝光 + 至少 500 名已验证粉丝 | 还需支持地区、Stripe、身份验证与合规 |
| Subscriptions | 18+、资料/邮箱/2FA、Premium、账号至少 3 月、近 30 天发帖、至少 2,000 名活跃 Premium 粉丝、近 3 月 500 万自然曝光 | 达标也不保证获批 |

## 通用变现要求

X Creator Monetization Standards 还要求：

- 年满 18 岁；
- 账号活跃至少 3 个月；
- 资料完整、邮箱验证、开启双重验证；
- 良好合规状态；
- 有效 Premium 订阅；
- 完成 Stripe 与身份验证。

支付名单核验时包含香港和台湾，未列中国大陆。X 明确保留修改或取消计划与门槛的权利，所以申请前必须重查官方页。

## “账号至少 3 个月”不是养号秘诀

这是特定变现产品的资格，不是普通帖子必须等待 3 个月才会获得推荐。普通账号可以在资料与安全完成后立即开始真实发布。

## X 明确禁止的增长动作

- follow churn：大量关注后取消关注来抬高粉丝；
- 短时间无差别关注/取关大量无关账号；
- 互换点赞、回复、转发、观看和关注；
- 购买或协调虚假互动；
- 批量相同回复、私信、Copypasta；
- 用无关热门标签或事件吸引曝光；
- 多账号协同人为放大或压制信息。

## 健康启动

1. 完善头像、简介、地区/网站和邮箱，开启 2FA。
2. 定义 3 个内容支柱，并准备一条置顶帖说明账号价值。
3. 以观点、现场照片/短视频、线程解释和真实回复组合发布。
4. 关注真实客户、行业工程师、品牌和媒体，不做批量关注任务。
5. 对趋势话题只在确实相关时参与，不塞无关标签。
6. 变现前核对 Premium、自然曝光、已验证粉丝、地区和 Stripe 条件。

## 美妆工厂适合的内容

- 一张不良品特写 + 一段原因解释；
- 15～30 秒工艺过程 + 关键参数边界；
- 采购争议的线程拆解；
- 展会、工厂、样品与设计趋势的现场信息；
- 对行业新闻的可验证补充，而不是复制标题。
