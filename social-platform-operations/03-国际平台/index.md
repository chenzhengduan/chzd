# 国际平台

本组覆盖 TikTok、Instagram、Facebook、YouTube、X 和 LinkedIn。前五个平台的创作者/变现门槛必须同时看四个条件；LinkedIn 页重点处理制造业 B2B 身份、Page、视频和获客流程：

1. 年龄；
2. 账号类型与合规状态；
3. 粉丝、观看或曝光数字；
4. 国家/地区及收款支持。

达到数字不等于自动通过。多数变现计划还会审核原创性、社区违规、身份、税务、收款和账号历史。
