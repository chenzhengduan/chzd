# 多平台发布前检查表

## 账号与资格

- [ ] 使用真实、已授权且长期可控的个人或企业主体
- [ ] 注册邮箱、手机号和恢复方式有效
- [ ] 已启用可用的双重验证
- [ ] 发布、直播、变现或带货功能在当前账号内显示可用
- [ ] 年龄、地区、账号类型和收款条件符合对应功能要求
- [ ] 企业管理员使用角色权限，没有共享个人密码

## 内容真实性

- [ ] 标题、封面、首帧和字幕与实际内容一致
- [ ] 工厂、产品、客户、产能、合格率和检测数据可核验
- [ ] 没有把演示、样品、素材库或其他现场说成真实生产结果
- [ ] 引用新闻、政策、研究或他人观点时标明来源
- [ ] 健康、金融、环保、食品级/医用级等结论有适用依据

## 权利与隐私

- [ ] 音乐、字体、图片、视频和模板允许当前商业用途
- [ ] 出镜者已同意肖像、声音、平台和使用期限
- [ ] 客户瓶型、图纸、订单、商标和检测报告允许公开
- [ ] 设备屏幕、白板、快递单和聊天记录没有泄露信息
- [ ] 未成年人内容已完成监护与平台要求

## AI 与剪辑

- [ ] 真实感 AI 合成人物、声音、地点或事件已按平台要求披露
- [ ] 没有用 AI 冒充客户、专家、员工或公众人物背书
- [ ] 没有伪造产品效果、测试、产线或新闻事件
- [ ] 必要时使用平台原生 AI/altered content 标签
- [ ] 轻微剪辑没有被描述成原创拍摄

## 商业与交易

- [ ] 付费、赠品、佣金、联盟或关联关系已披露
- [ ] 使用平台允许的 Paid partnership/品牌内容/商业推广工具
- [ ] 商品、服务、类目和宣传用语符合当地法律与平台规则
- [ ] 联系方式只放在平台允许的位置
- [ ] 没有诱导脱离平台进行高风险私下交易

## 互动与增长

- [ ] 没有购买粉丝、播放、观看时长、点赞、评论或转发
- [ ] 没有互粉互赞、sub4sub、follow churn 或奖励换互动
- [ ] 没有批量复制评论、私信和无关标签
- [ ] 多账号内容有真实受众与表达差异，不是无差别铺量
- [ ] 外包机构承诺遵守平台规则，并可审计推广来源

## 发布后留证

- [ ] 保存成片、文案、封面、授权和发布日期
- [ ] 记录平台、链接、内容 ID 和使用的披露工具
- [ ] 记录账号状态、版权匹配、限制和申诉通知
- [ ] 复盘真实指标，不把低播放自动判断为限流
- [ ] 规则发生变化时更新页面核验日期
