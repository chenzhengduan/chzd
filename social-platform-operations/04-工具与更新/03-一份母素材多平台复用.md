# 一份母素材，多平台合规复用

> 这是制造业内容的降本流程，不是平台硬规则。核心是保存自己拥有权利的干净母版，再按平台和受众重新包装。

## 先保存 3 层文件

```text
01_SOURCE  原始画面、现场声、授权记录
02_MASTER  无字幕、无音乐、无平台水印的剪辑母版
03_EXPORT  TikTok / 抖音 / 小红书 / LinkedIn 等平台版本
```

母版旁边保存客户授权、人物授权、商标、参数来源、AI 使用和商业关系披露。资产台账只记录位置与负责人，不保存密码或恢复码。

## 每个平台重做 6 项

| 项目 | 为什么要重做 |
| --- | --- |
| 首帧与前两秒 | 用户场景和界面不同 |
| 时长与节奏 | 同一问题在各平台的解释深度不同 |
| 字幕密度 | 阅读习惯、语言和安全区不同 |
| 标题与正文 | 搜索型、关系型和推荐型场景不同 |
| 音乐与声音 | 授权范围可能只覆盖某个平台 |
| CTA 与披露 | 私信、主页、表单和商业披露工具不同 |

## 制造业常用改编方向

以下是 C 级运营建议，不是平台强制规则：

- TikTok / 抖音：动作证据、快速对比、过程变化；
- 小红书 / Instagram：选择清单、效果差异、收藏型说明；
- YouTube / 哔哩哔哩：完整工艺、测试过程、故障解释；
- 视频号 / Facebook：团队、客户关系和已有社交网络承接；
- LinkedIn：采购判断、质量边界、团队专业性和 B2B 下一步；
- X：展会、行业现场、即时观察和公开讨论。

## 不能直接复用的东西

- 他人画面、平台水印或未获授权的客户素材；
- 只在某平台获得授权的音乐；
- 完全相同的标题、标签和导流话术；
- 未经复核的参数、功效、认证或价格；
- 已失效的商业披露和 AI 标识。

不要把规则误写成“同一素材不能跨平台发”。自有原始画面可以复用，关键是权利清楚、没有他人水印，并且为目标平台增加真实的表达价值。

## 发布前 2 分钟检查

- [ ] 使用的是干净母版，不含其他平台水印；
- [ ] 音乐、人物、客户和商标授权覆盖本平台；
- [ ] 首帧、字幕和 CTA 已按本平台重做；
- [ ] 重要参数和声明仍然准确；
- [ ] 商业合作、AI 内容等完成必要披露；
- [ ] 保存平台版本、内容编号和发布时间。

## 规则依据

- [TikTok Integrity and Authenticity](https://www.tiktok.com/community-guidelines/en/integrity-authenticity/)：限制无新增价值的复用、他人水印和虚假互动等行为；
- [Facebook：Rewarding Original Creators（2026）](https://about.fb.com/news/2026/03/rewarding-original-creators-on-facebook/)：说明账号所有者亲自拍摄或制作的内容属于原创内容范畴。

具体推荐资格与原创判断仍以各平台当期规则和账号内状态为准。
